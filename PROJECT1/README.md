PROJECT OVERVIEW

This project was completed as part of my Data Analyst Internship at Decode Labs.

The main objective of this project was to clean and prepare raw data using Microsoft Excel. Various data cleaning techniques were applied to improve data quality, consistency, and accuracy, making the dataset suitable for further analysis.

## Tools Used

- Microsoft Excel
- Data Cleaning
- Data Formatting
- Data Validation
- Data Analysis

## Key Tasks Performed

- Identified and handled missing values
- Removed duplicate records
- Corrected inconsistent data
- Standardized data formats
- Checked data quality and consistency
- Prepared the cleaned dataset for analysis

# Outcome

The raw dataset was transformed into a cleaner and more structured dataset that could be reliably used for further data analysis and visualization.
