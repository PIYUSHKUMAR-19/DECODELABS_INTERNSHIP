# Project 2 – Data Scraping, Cleaning & Reprocessing Using Python

## Project Overview

This project was completed as part of my Data Analyst Internship at Decode Labs.

The main objective of this project was to collect, clean, validate, and reprocess data using Python. The project involved extracting data from web sources, handling missing and inconsistent data, validating the collected information, and transforming the raw data into a structured and analysis-ready format.

## 🛠️ Tools Used

- Python
- Pandas
- Web Scraping
- Data Cleaning
- Data Validation
- Data Reprocessing
- Data Transformation

##  Key Tasks Performed

- Scraped data from web sources using Python
- Collected and structured raw data
- Identified and handled missing values
- Detected and corrected inconsistent data
- Performed data validation and quality checks
- Reprocessed and transformed the collected data
- Prepared the final dataset for further analysis

## Outcome

The raw scraped data was cleaned, validated, reprocessed, and transformed into a structured and analysis-ready dataset, improving its quality and reliability for further data analysis.
